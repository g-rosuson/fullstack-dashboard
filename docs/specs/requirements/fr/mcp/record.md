# Record

What is kept for a prompt.

- **FR-MCP-REC-001** — The system shall keep each tool or resource it uses and the arguments passed to it.
- **FR-MCP-REC-002** — The system shall keep the result of each tool call and each resource read.
- **FR-MCP-REC-003** — The system shall keep all content it passes to the model for a prompt.
- **FR-MCP-REC-004** — When a prompt finishes with an answer, the system shall keep that prompt's permission asks, call steps, times, and tool and resource record on the saved turn.
