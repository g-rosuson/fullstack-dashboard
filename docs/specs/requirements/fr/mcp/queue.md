# Queue

The current tool or resource while a prompt uses it, and the saved events of a turn.

- **FR-MCP-QUE-001** — While a prompt is being answered, the system shall show the current tool or resource, one at a time.
- **FR-MCP-QUE-002** — The system shall show the name of that tool or resource.
- **FR-MCP-QUE-003** — The system shall show a turn's saved events when those events are available, and shall not show them before that.
- **FR-MCP-QUE-004** — Saved events shall be collapsed until the user opens them.
