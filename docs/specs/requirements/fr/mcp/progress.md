# Progress

What is reported while a prompt is being answered.

- **FR-MCP-PRG-001** — While a prompt is being answered, the system shall report each step as that step happens.
- **FR-MCP-PRG-002** — The system shall report when the model asks for the list of tools and resources.
- **FR-MCP-PRG-003** — The system shall report when it asks the user for permission.
- **FR-MCP-PRG-004** — The system shall report when a tool or resource starts, finishes, or fails.
- **FR-MCP-PRG-005** — The system shall report when it writes the answer.
- **FR-MCP-PRG-006** — The system shall report when the prompt started and when the answer finished.
- **FR-MCP-PRG-007** — The system shall report which tools and resources a finished answer used.
- **FR-MCP-PRG-008** — The system shall report when the user refuses a tool or resource.
