# Order

How tools and resources run for one prompt. A tool or resource the user attached is already permitted. One the system selected runs only after the user allows that ask. A refusal does not run it.

- **FR-MCP-ORD-001** — The system shall run the tools and resources of one prompt one after another.
- **FR-MCP-ORD-002** — The system shall run a tool or resource only after it is permitted.
