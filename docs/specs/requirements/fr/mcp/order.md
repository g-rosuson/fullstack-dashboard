# Order

How tools and resources run for one prompt. The model selects the next one after the previous one finished or was refused. Each runs after the user allows that ask. A refusal skips it.

- **FR-MCP-ORD-001** — The system shall run the tools and resources of one prompt one after another.
- **FR-MCP-ORD-002** — The system shall run a tool or resource only after it is permitted.
