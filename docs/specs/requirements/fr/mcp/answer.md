# Answer text

How a finished answer, a prompt, and a tool or resource result are shown.

- **FR-MCP-ANS-001** — The system shall show a finished answer as formatted text, including its headings, lists, and tables.
- **FR-MCP-ANS-002** — The system shall show a prompt as it was typed.
- **FR-MCP-ANS-003** — The system shall show a tool result and a resource result as plain text.
- **FR-MCP-ANS-004** — When a finished answer cannot be shown as formatted text, the system shall show that answer's original text.
