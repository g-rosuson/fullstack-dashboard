# Queue status

How the current tool or resource is shown as it runs. One status is shown at a time.

- **FR-MCP-QST-001** — The system shall show the current tool or resource as processing, succeeded, or failed.
- **FR-MCP-QST-002** — The system shall show a failed tool or resource as failed, distinct from succeeded.
- **FR-MCP-QST-003** — The system shall show a refused tool or resource as refused, distinct from processing, succeeded, and failed.
