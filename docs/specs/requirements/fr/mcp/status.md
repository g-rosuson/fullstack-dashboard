# Queue status

How a tool or resource in the queue is shown as it runs.

- **FR-MCP-QST-001** — The system shall show a tool or resource as processing, succeeded, or failed.
- **FR-MCP-QST-002** — The system shall mark a failed tool or resource so it is distinct from one that succeeded.
- **FR-MCP-QST-003** — The system shall show a refused tool or resource as refused, distinct from processing, succeeded, and failed.
