# Conversations

- **FR-LLM-CNV-001** — The system shall allow the user to create more than one conversation.
- **FR-LLM-CNV-002** — When the user opens a conversation, the system shall show its prompts and answers.
- **FR-LLM-CNV-003** — The system shall keep each conversation, including its prompts and answers, until the user deletes it.
- **FR-LLM-CNV-004** — The system shall allow the user to delete a conversation.
- **FR-LLM-CNV-005** — After deletion, the system shall not show that conversation again.
