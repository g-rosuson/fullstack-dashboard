# Selection

Examples of domains are WhatsApp and email. A resource is something the prompt can read, for example a file.

Chooser accessibility: [`nfr/accessibility/ui.md`](../../nfr/accessibility/ui.md).

- **FR-LLM-SEL-001** — The system shall group tools and resources by domain.
- **FR-LLM-SEL-002** — The system shall allow the user to attach every tool and resource in a domain.
- **FR-LLM-SEL-003** — The system shall allow the user to attach or skip each tool and each resource, including items from more than one domain.
- **FR-LLM-SEL-004** — While the user is writing a prompt, the system shall show each attached tool and resource with its domain and name.
