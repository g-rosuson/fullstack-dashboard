# Prompt

What the user attaches is [FR-LLM-SEL-*](./selection.md).

- **FR-LLM-PRM-001** — The system shall answer the user’s prompt.
- **FR-LLM-PRM-002** — With nothing attached, the system shall answer from general knowledge and shall not use tools or resources.
- **FR-LLM-PRM-003** — With tools or resources attached, the system shall use them where the prompt needs them.
