# Navigation

A navigation listing exposes named destinations and which one is current.

- **FR-UI-NAV-001** — A navigation listing shall expose each destination with an accessible name.
- **FR-UI-NAV-002** — A navigation listing shall indicate which destination is current.
- **FR-UI-NAV-003** — Activating a destination shall take the user to that destination.
- **FR-UI-NAV-004** — A navigation listing shall show an icon with a destination when one is provided, and shall not show an icon when none is provided.
