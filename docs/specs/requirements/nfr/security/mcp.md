# MCP security

Who can reach the MCP server, and how answer text is shown. Who can call the server is under [fr/mcp/exposure.md](../../fr/mcp/exposure.md).

- **NFR-SEC-MCP-001** — HTML in a finished answer shall be shown as text and shall not be executed.
- **NFR-SEC-MCP-002** — The MCP server shall be unreachable from the public internet.
