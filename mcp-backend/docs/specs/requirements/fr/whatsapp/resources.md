# WhatsApp chats

- **FR-WHATSAPP-RES-001** — The system shall list a family chat and a work chat. Each listed chat shall include a description and a URI whose scheme is whatsapp.
- **FR-WHATSAPP-RES-002** — The system shall return the messages stored for a listed chat when that chat is read.
- **FR-WHATSAPP-RES-003** — The system shall refuse a read for a chat that is not listed.
- **FR-WHATSAPP-RES-004** — The system shall advertise a template that names one chat. Listing chats shall not repeat a listed chat because of that template.
