# WhatsApp tools

- **FR-WHATSAPP-CHT-001** — The system shall return the listed chats, including each chat's URI, when asked for recent chats.
- **FR-WHATSAPP-MSG-001** — The system shall accept a listed chat and a message and return a receipt that the message was sent. That chat's messages shall remain unchanged.
- **FR-WHATSAPP-MSG-002** — The system shall refuse a message whose chat is not listed.
